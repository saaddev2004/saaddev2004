## About Me

I'm a **Software Engineer** and **Full-Stack Developer** working across both **web and app platforms**, currently in my final year of BS Software Engineering at the University of Central Punjab. I build complete, working products — not just tutorial clones. My core is the **MERN stack**: React and React Native front ends wired to Express/Node APIs, backed by MongoDB, with real authentication, role-based access, and admin tooling — the kind of detail that separates a portfolio piece from a production system.

Alongside that, I'm also doing hands-on work in **AI/ML** — applied machine learning, LLM-based tooling, and the early stages of retrieval-augmented systems — while leading the architecture of my final-year project, a three-sided marketplace platform with AI-driven verification and escrow payments.

What I care about:
- **Systems that hold up under real constraints** — auth security, data integrity, role separation, error handling — not just happy-path demos
- **Clear architecture** — MVC on the backend, context-driven state on the frontend, decoupled and documented
- **Shipping** — every project below is deployed and reachable, not just sitting in a repo

## Featured Projects

### 🛍️ Shop.co — Full-Stack MERN E-Commerce Platform

A complete online store built on MongoDB, Express, React, and Node — covering the full retail flow, not just a product catalog.

- **What it solves:** end-to-end commerce — guest and authenticated checkout, order lifecycle tracking, and a real admin back office, in one codebase
- **Key features:** JWT auth over HttpOnly cookies (not localStorage, to reduce XSS exposure), role-based access control, an admin dashboard with live analytics, per-color/size inventory tracking, and a review system enforced with a compound unique index
- **Architecture:** decoupled `frontend/` (React SPA) and `backend/` (Express REST API), MVC-structured server, global state via React Context
- **Stack:** `React 19` · `React Router v7` · `Tailwind CSS` · `Node.js` · `Express 5` · `MongoDB` · `Mongoose` · `JWT` · `bcryptjs`

### 🏋️ Structure Health & Fitness — Gym & Membership Platform

A responsive marketing and membership site for a fitness center, backed by a real API rather than static content.

- **What it solves:** gives a multi-branch fitness business a single, dynamic front door — membership plans, branch locations, and lead capture, all in one site
- **Key features:** animated UI sections built with Framer Motion, Google Maps integration for branch locations, reCAPTCHA-protected contact forms, and Chart.js-driven stats
- **Architecture:** React frontend consuming a Node/Express + MongoDB backend, cleanly separated by concern (`components/`, `pages/`, `sections/`)
- **Stack:** `React` · `React Router` · `Bootstrap` · `Framer Motion` · `Node.js` · `Express` · `MongoDB` · `Mongoose`

### 📱 Vynce — Social Media Platform

A mobile-first social networking application focused on the core loop every social app lives or dies by: profiles, posts, and engagement.

- **What it solves:** a clean, purpose-built space for user profiles, content sharing, and social interaction, built as a mobile application
- **Key features:** user profiles, a content feed, and social engagement mechanics (likes/comments-style interaction), designed around a modern MERN-style stack
- **Architecture:** structured as a full-stack app with a dedicated backend API layer, following the same MVC-first discipline used across other projects
- **Stack:** `React Native` · `Node.js` · `Express` · `MongoDB`
